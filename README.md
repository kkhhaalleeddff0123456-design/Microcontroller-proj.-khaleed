## 2. Description

The Vehicle Dashboard is a digital instrument cluster built as a set of
independent modules that share a common scheduler and data model
(`CarData_t`). Each module owns one job: measuring a signal, driving an
output, or managing a piece of state.

## 4. M1 — Gauges Module (DONE)

**Owns:** ADC acquisition and scaling for the four analog sensors.

| Signal | Pin | ADC ch. | Engineering range | Formula |
|--------|-----|:-------:|--------------------|---------|
| Fuel level | `PA0` | ADC0 | 0 – 100 % | `raw*100/1023` |
| Coolant temperature | `PA1` | ADC1 | 40 – 130 °C | `(raw*170/1023) - 40` |
| Battery voltage | `PA2` | ADC2 | 0.0 – 16.0 V | `raw*16000/1023` |
| Oil pressure | `PA3` | ADC3 | 0.0 – 10.0 bar | `raw*100/1023` |

- Sample rates: fuel/coolant 2 Hz (heavily damped, 8-sample moving average),
  battery/oil 10 Hz (median-of-3 filter).
- All scaling intermediates use `uint32_t`.
- Public API: `GAU_Update`, `GAU_Fuel`, `GAU_CoolantC`, `GAU_BattmV`,
  `GAU_OilBarX10`.
- Feeds warning thresholds: low fuel < 10 %, oil < 1.0 bar, coolant > 110 °C,
  battery outside 12.0 – 15.0 V.

## 5. M2 — Speedometer Module (DONE)

**Owns:** road-speed measurement from the wheel-speed pulse train.

| Item | Value |
|------|-------|
| Pin | `PD6` / `ICP1` |
| Technique | Timer1 Input Capture, period measurement |
| Timer config | Normal mode, prescaler 64, `ICIE1` + `TOIE1`, noise canceller on, rising edge |
| Wheel sensor | 4 pulses/rev, 2.000 m circumference → 500 mm/pulse |
| Output rate | 10 Hz |

- 16-bit capture is extended to 32 bits with a `TIMER1_OVF_vect` counter so
  speeds down to ~1 km/h remain measurable.
- No division inside the ISR — km/h conversion happens in the 100 ms task.
- Zero-speed detection: no edge for 1 s → speed reported as 0.
- Implausible readings (> 250 km/h) are rejected as noise.
- Public API: `SPD_OnCapture`, `SPD_OnOverflow`, `SPD_GetKmh`.

---

## 6. M3 — Tachometer Module (DONE)

**Owns:** engine RPM from ignition pulses.

| Item | Value |
|------|-------|
| Pin | `PD2` / `INT0` |
| Technique | Rising-edge pulse counting over a fixed 250 ms window |
| Engine | 4-cylinder 4-stroke, 2 ignition pulses/crank revolution |
| Formula | `RPM = count × 120` |
| Output rate | 4 Hz |

- Counter is read and zeroed atomically at each window boundary.
- Accuracy target: ±60 RPM from 600–6000 RPM.
- Engine declared **running** when RPM > 500 for 500 ms, **stalled** when
  RPM < 300 for 1 s while running.
- Public API: `TAC_OnPulse`, `TAC_Update250ms`, `TAC_GetRpm`.

## 7. M4 — Turn Indicator Module (DONE)

**Owns:** left/right turn signal and hazard blinking.

| Signal | Pin | Notes |
|--------|-----|-------|
| Turn-left switch | `PB0` | In, pull-up, active low |
| Turn-right switch | `PB1` | In, pull-up, active low |
| Left lamp | 74HC595 `Q5` | Green |
| Right lamp | 74HC595 `Q6` | Green |

- Blink rate: 450 ms on / 450 ms off (≈ 67 flashes/min), generated by the
  scheduler tick — not a delay loop.
- Both switches active at once → hazard mode: both lamps blink in phase.
- Releasing a switch extinguishes its lamp within one blink period.
- A synchronized buzzer tick accompanies each blink (see Chime Module).

## 8. M5 — Warning Lamps Module (DONE)

**Owns:** the 8-lamp cluster, driven through a 74HC595 shift register that
shares the SPI bus with the EEPROM.

| Q output | Lamp | Colour | Priority |
|:--------:|------|--------|:--------:|
| `Q0` | Low fuel | Amber | 5 |
| `Q1` | Oil pressure | Red | 1 |
| `Q2` | Battery / charging | Red | 2 |
| `Q3` | Coolant temperature | Red | 3 |
| `Q4` | Check engine | Amber | 4 |
| `Q5` | Left turn | Green | — |
| `Q6` | Right turn | Green | — |
| `Q7` | High beam | Blue | — |

**Shared-bus rules:**
- `SPI_Acquire(slave)` / `SPI_Release()` bracket every transaction; never
  assert a second chip-select while another is low.
- 74HC595 has no `MISO` — never read `SPDR` expecting data from it.
- Latch pin `PC2` (`RCLK`) is pulsed **after** `SPI_Release()`, never mid-byte.
- An EEPROM write owns the bus for its full multi-step sequence; the lamp
  task simply waits one tick if the bus is busy (50 ms → 100 ms refresh is
  still flicker-free).

**Priority resolution** (lowest number wins on the LCD banner; all lit lamps
still show in `warnMask`):

| Priority | Warning | Condition | Class |
|:--------:|---------|-----------|-------|
| 1 | Oil pressure | < 1.0 bar, engine running, 2 s | Critical → limp home |
| 2 | Battery | < 12.0 V or > 15.0 V, 5 s | Critical |
| 3 | Coolant | > 110 °C, 3 s | Critical → limp home |
| 4 | Check engine | Any sensor implausible | Warning |
| 5 | Low fuel | < 10 % | Warning |
| 6 | Over-speed | Above limit | Warning |
| 7 | Seatbelt | Unbuckled + > 10 km/h | Info |
| 8 | Door | Open + > 5 km/h | Info |
| 9 | Handbrake | Engaged + > 5 km/h | Info |

- Bulb check: entering ignition lights all 8 lamps for 3 s, then settles to
  actual conditions.
- Public API: `LMP_Set`, `LMP_Refresh`, `LMP_BulbCheck`, `WRN_Update`,
  `WRN_Highest`, `WRN_Mask`.

## 9. M6 — Odometer Module (DONE)

**Owns:** distance integration and crash-safe EEPROM persistence.

- Each wheel-speed pulse adds 500 mm to a running total; whole metres carry
  into lifetime odometer and trip meter (exact integration, no drift).
- **Save policy:** write every 100 m travelled *or* every 60 s, whichever
  comes first, plus immediately on key-off.
- **Wear-levelling:** 8 EEPROM slots on the 25LC256; each write targets the
  next slot while the previous slot is left untouched, so a power cut
  mid-write loses at most 100 m and never corrupts the odometer.
- At 100 m/write and ~1M erase cycles per cell, the scheme supports roughly
  800,000 km before wear becomes a concern.
- Trip meter is reset by holding the trip-reset button 2 s (a short press
  instead cycles the display page); lifetime odometer is untouched by a
  trip reset.
- Public API: `ODO_AddDistance`, `ODO_GetTotal`, `ODO_GetTrip`,
  `ODO_ResetTrip`.

## 10. M7 — Display Module (DONE)

**Owns:** the 16×2 LCD (via PCF8574 I2C expander) and page cycling.

| Page | Content |
|------|---------|
| `PG_MAIN` | Speed + primary warning banner |
| `PG_TRIP` | Trip distance, average speed |
| `PG_ENGINE` | RPM, coolant |
| `PG_ELECTRICAL` | Battery voltage |
| `PG_DIAG` | Diagnostics |

- Display-cycle button advances pages; bulb check and limp-home banners
  override the normal page temporarily.
- Public API: `DSP_Next`, `DSP_Render`.

## 11. M8 — Ignition FSM Module (DONE)

**Owns:** the ignition key state machine.

```
OFF → ACC → IGNITION → BULBCHECK → CRANKING → RUNNING
                                       ↕
                                   LIMP_HOME / STALLED
```

- Ignition key presses step `OFF → ACC → IGNITION`; a 2 s hold returns to
  `OFF`.
- Start button only honoured in `CS_IGNITION`, after the bulb check.
- Cranking capped at 5 s; on timeout, returns to `CS_IGNITION`.
- `CS_RUNNING` entered when RPM > 500 for 500 ms.
- Stall: RPM < 300 for 1 s while running → `CS_STALLED`.
- Limp-home: a critical warning (oil or coolant) latches `CS_LIMP_HOME` for
  the rest of the key cycle, with a chime pattern and alternating LCD banner.
- Public API: `FSM_Init`, `FSM_Run`, `FSM_GetState`.

---

## 12. M9 — Console Module

**Owns:** the UART diagnostics port (9600 8N1).

- Parses one command line at a time (e.g. `SET LIMIT`, `SAVE`, `SLOTS?`).
- `SET ODO` is protected — refused unless explicitly unlocked.
- Emits a periodic diagnostics/telemetry frame and event lines
  (`!EVT,...`) for record events, faults, and limp-home entry.

---

## 13. M10 — Chime Module

**Owns:** buzzer tone patterns on `PD7`/OC2 (Timer2 PWM).

- Turn-signal tick (synced with M4's blink phase).
- Over-speed chime: once, then every 5 s while over the limit.
- Limp-home chime: continuous for 5 s, then one chirp every 10 s.
